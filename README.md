# Ivo's 60th Birthday

RSVP website for Dr. Ivo Nkemanyang's 60th birthday celebration — 24th October 2026, Derby.

Static site (no build step). Open `index.html` directly or serve the folder with any static file server.

To finish setting up the RSVP form, edit `index.html` and replace the placeholder `src` in the `.rsvp__iframe` with your Google Form's embed URL (Send → Embed `<>` in Google Forms).
